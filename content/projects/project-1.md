## Objective

Write one pattern that holds a listener's attention for a full minute, using
only what week 3 covered. No effects, no notes, no functions beyond `sound`,
`n`, `bank` and `setcpm`. The whole piece is one string of mini-notation.

The restriction is the assignment. Anyone can make a minute of audio with more
tools; the question here is how much you can get out of sequences, rests,
subdivisions, alternation, and a choice of drum machine.

## Requirements

- Three or more voices separated by commas.
- At least one `<>` group, so the pattern takes more than one cycle to repeat.
- At least one `[ ]` subdivision.
- At least one rest, used because you want the hole and not because you ran
  out of ideas.
- A `bank()` you picked deliberately and can defend in one sentence.
- Written across several lines using backticks, so it stays readable.

## What to hand in

Paste the pattern as text on D2L. Not audio, not a screenshot — the code
itself, so I can run it. Include two sentences: the constraint you set for
yourself beyond the ones above, and the one edit that made the biggest
difference.

## How it is graded

| | |
|---|---|
| Meets all six requirements | 30% |
| Holds up over a full minute rather than looping flat | 30% |
| Deliberate choices you can explain | 20% |
| Readable code, sensibly laid out | 20% |

## Starting point

If you are stuck, take the etude 5 pattern and grow it. Add a third voice,
then make one of the `<>` groups longer, then find the drum machine that suits
what you built.
